# Контракты API CodeHogwarts

**Базовый URL сервера: [https://maks.my/codehog](https://maks.my/codehog)**
   
**Интерактивная спецификация (Swagger UI): [https://maks.my/codehog/hog/docs](https://maks.my/codehog/hog/docs)**
   
**Префикс API:** Эндпоинты вынесены под префикс /hog/, чтобы избежать конфликта с другим приложением на порту 8787.

**Точка проверки работоспособности:** GET /health   

## Аутентификация и сессии

**Сессия ученика:** Подписанная cookie codehog_session (библиотека itsdangerous, HttpOnly, SameSite=Lax, срок жизни — 30 дней). Подделка на клиенте невозможна, так как подпись проверяется ключом SECRET_KEY.   

**Гостевая сессия:** Cookie codehog_guest (срок жизни — 1 сутки). Используется для привязки результатов стартовой диагностики к аккаунту при последующей регистрации.   

## 1. HTML Страницы (Frontend-рендер)
   
Эти методы возвращают text/html для отображения в браузере.   

* GET / — Лендинг. Если пользователь уже вошел, происходит редирект на /app.   

* GET /test — Диагностика.   

* GET /register — Регистрация. Уровень подготовки автоматически подставляется из пройденной диагностики.   

* GET /login или POST /login — Вход по почте или логину.   

* GET /logout — Выход.   

* GET /lang/{code} — Переключение языка (ru, en, ce).   

* GET /app — Карта курса, персонаж, колесо фортуны (доступно только ученику).   

* GET /lesson/{id} — Урок. Если запрашивается чужой урок, происходит редирект на /app.   

* GET /shop — Магазин (доступно только ученику).   

* GET /admin — Панель администратора. Гостей перенаправляет на страницу входа, пользователям без прав админа возвращает ошибку 404.   

## 2. Учебный модуль (Hogwards / Tasks)

**POST /hog/test/submit** 

**Название:** Проверить тест (Диагностика)

**Описание:** Принимает ответы этапа, отдаёт следующий вопрос или итоговый результат. Правильные ответы клиенту не отправляются.

**Формат тела:** application/json

`{ "answers": [ { "id": "M1", "answer": "[0, 4, 16]" } ] }`

Ответ (пока тест не окончен):

`{ 
  "done": false, 
  "questions": [ { "id": "H1", "difficulty": "hard", "topic": "аргументы по умолчанию", "text": "...", "code": "...", "options": ["..."] } ], 
  "progress": 3 
}`

Ответ (по завершении):

`{ 
  "done": true, 
  "level": "advanced", 
  "level_label": "Продвинутый", 
  "correct": 5, 
  "total": 6, 
  "weak_topics": ["генераторы"], 
  "explanations": [ { "id": "H3", "correct": false, "text": "..." } ] 
}`

**POST /hog/task/{task_id}/check**

**Название:** Проверить Задание

**Формат тела:** application/json (Для заданий без кода вместо code передаётся answer).

`{ "code": "def solve(numbers):\n    return sum(n for n in numbers if n % 2 == 0)" }`

Успешный ответ (200 OK): Возвращается в любом случае после проверки, даже если ответ неверный. Блок lesson_done приходит только при решении последнего задания в уроке.

`{ 
  "correct": true, 
  "output": "", 
  "error": "",  
  "checks": [ { "call": "solve([1, 2, 3, 4])", "expected": 6, "got": 6, "passed": true, "error": "" } ],  
  "explanation": "...", 
  "hint": "...",  
  "lesson_done": { "coins": 25, "xp": 20, "streak": 1, "spins": 0, "capped": false } 
}`

Ошибки: 401 (Не выполнен вход), 404 (Задание не существует или принадлежит другому пользователю).   

**POST /hog/task/{task_id}/hint**

**Название:** Подсказка

**Описание:** Возвращает подсказку по коду ученика. Без ключа модели возвращается статичная подсказка с параметром source: "static".

**Формат тела:** application/json ({ "code": "..." }).

Ответ:

`{ 
  "hint": "Обратите внимание на условие чётности...", 
  "source": "deepseek-v4-flash" 
}`

## 3. Геймификация и Магазин (Shop & Wheel)

**GET /hog/wheel/state**

**Название:** Состояние Колеса

Ответ:

`{ 
  "spins": 2, 
  "coins": 275,  
  "sectors": [ 
    {"coins": 10, "weight": 45}, 
    {"coins": 20, "weight": 30},               
    {"coins": 40, "weight": 18}, 
    {"coins": 80, "weight": 6},               
    {"coins": 150, "weight": 1} 
  ] 
}`

**POST /hog/wheel/spin**

**Название:** Крутить Колесо

**Описание:** Приз определяется на сервере до анимации. Повторный запрос за ту же веху не даст новых монет.

Ответ (200 OK):

`{ "sector": 2, "coins_won": 40, "coins": 315, "spins_left": 1 }`

Ошибки: 400 ("Вращений пока нет — пройдите ещё уроки"), 401 (Не выполнен вход).

**POST /hog/shop/buy/{sku}**

**Название:** Купить предмет

**Параметры пути:** sku (идентификатор товара).

Ответ (200 OK):   

`{ "ok": true, "coins": 235, "equipped": true, "slot": "head", "asset": "cap" }`

Ошибки: 400 ("Не хватает N монет"), 404 (Предмета нет в каталоге).  

**POST /hog/shop/equip/{sku}**

**Название:** Надеть / Снять

**Описание:** Переключает статус предмета "надето / снято".

Ошибки: 404 (Предмет не куплен).

## 4. Панель Администратора (Admin)

Все эндпоинты требуют роли администратора.

**Формат тела запросов: application/x-www-form-urlencoded.**

* POST /admin/bonus — Раздать бонус всем (параметры: amount, comment).   

* POST /admin/reset — Сбросить собственный прогресс (для проверки воронки).   

* POST /admin/reset/{user_id} — Сбросить прогресс указанного пользователя.   

* POST /admin/unlock — Открыть весь каталог магазина администратору.   

* POST /admin/complete — Отметить весь курс пройденным.   

## 5. Общие правила обработки ошибок

Все системные ошибки возвращаются в формате JSON: {"detail": "текст на русском"} с соответствующим HTTP-кодом. Стек-трейсы (stack traces) наружу не отдаются.

GET /health — проверка статуса сервера (возвращает 200 OK с состоянием сервиса).
