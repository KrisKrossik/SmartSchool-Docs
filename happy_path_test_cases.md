# Спецификация тест-кейсов (Happy Path)

**Проект:** Образовательная платформа «CodeHogwarts» (HOG)  
**Тип тестирования:** Функциональное тестирование положительных сценариев (Happy Path)  
**Покрытие:** Use Cases 1–7, Функциональные и Архитектурные требования (Блоки 1–6)

---

Каждая ссылка открывает соответствующий документ в модальном окне или новой вкладке без ошибок 404.<br>2. Текст документов читаем и доступен до завершения регистрации. |
